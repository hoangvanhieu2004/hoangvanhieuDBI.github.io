# Hoàng Văn Hiếu | Data Analyst Portfolio

Personal portfolio website, hosted on GitHub Pages: https://hoangvanhieu2004.github.io/hoangvanhieuDBI.github.io/

The site is bilingual. Click **EN | VI** in the navigation bar to switch between English and Vietnamese; the choice is remembered on the next visit.

## Editing

- `index.html` holds the page structure and the **English** text.
- `assets/js/main.js` holds the **Vietnamese** text in the `VI` object. Every element with `data-i18n="key"` in `index.html` has a matching key there. When you add or change text, update both places.
- `assets/css/style.css` holds the styles.
- Project preview images are in `assets/images/projects/`.
